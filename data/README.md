# data/

- `raw/` — real Kaggle `twcs.csv` goes here (not committed; `.gitignore`d). Download from
  https://www.kaggle.com/datasets/thoughtvector/customer-support-on-twitter
- `mock_raw/` — synthetic sample matching the real schema, generated by
  `scripts/generate_mock_data.py`. Used only because this dev environment
  has no internet access to fetch the real file. Fictional brand names
  (`MockBrandA`/`MockBrandB`) to avoid any confusion with real companies.
- `processed/` — derived, cleaned customer/support pairs for the selected
  brand (`scripts/build_sample.py` output). Never the raw dataset itself.
- `golden/` — the held-out golden evaluation set (`scripts/build_golden_set.py`
  output). Never used for retrieval or training - see `src/data/sampling.py`.
- `intent_taxonomy.json` — the 7-intent taxonomy derived from clustering
  this brand's own messages (`scripts/discover_intents.py`), hand-named.

The original/raw dataset is never modified - only derived and sampled
data is stored in this repo.
